# Importer des données

Hyvor Blogs propose plusieurs méthodes pour importer des données depuis votre blog existant :

- [Sitemap](/docs/import-sitemap) : Importez des articles à partir de votre fichier sitemap.xml. Prend en charge tous les types de blogs. Votre blog doit être public.
- [WordPress](/docs/import-wordpress) : Importez des articles à partir d'une exportation WordPress ou compatible WordPress.
