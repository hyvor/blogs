# Introduction

Hi there blogger 👋,

Running a blog has never been easier. Installing plugins, keeping up with updates, and managing services are not for general bloggers. We believe that blogging should be easy for everyone. That's why we created [Hyvor Blogs](/). All the technical stuff is handled by us. You just need to focus on writing.

<h2 id="get-started">How to get started?</h2>

Visit the [Hyvor Blogs Console](https://blogs.hyvor.com/console) to create a new blog. The Console is where you will be managing all of your blogs. You can access the Console using your HYVOR account. Each account can have multiple blogs.

<h2 id="features">Features</h2>

Hyvor Blogs is an all-in-one blogging platform. Here are some of its main features with links to learn more about them.

- **[Powerful writing tools](/docs/writing)** - You can write your posts in the built-in rich text editor. Adding images, rich media, and code snippets are easy-peasy.
- **[Multi-language support](/docs/languages)** - Want to reach a wider audience? Enable multiple languages for your blog and start translating. We support AI translations via DeepL as well.
- **[Customizable Themes](/docs/theme)** - You can choose a theme from our theme library or create your own theme from scratch.
- **[Invite your team members](/docs/users)** - Write posts with your team members. Multiple roles are available.
- **[Custom Domain](/docs/custom-domain)** - Host your blog on your own domain like example.com or blog.example.com.
- **[Sub-directory Hosting](/docs/subdirectory)** - Host your blog on your a sub-directory like example.com/blog. Multiple integrations are available.
- **[In-built SEO](/docs/seo)** - Hyvor Blogs is built with SEO in mind. Most of the technical SEO stuff is handled by us. You just need to focus on writing.
- **[Integrations via Custom Code](/docs/custom-code)** - Want to add analytics, ads, or other integrations? Just add the code snippet to the Custom Code section.
