# Importer depuis WordPress

Actuellement, l'importation depuis WordPress n'est disponible que via le support. Veuillez nous contacter à <a href="mailto:blogs.support@hyvor.com">blogs.support@hyvor.com</a> pour importer votre blog WordPress.

Suivez les étapes ci-dessous pour exporter votre site WordPress :

- Exportez vos articles depuis **WordPress admin &rarr; Outils &rarr; Exporter &rarr; Tout le contenu &rarr; Télécharger le fichier d'export**
- Téléchargez votre dossier `wp-content/uploads` depuis votre site WordPress. Ce dossier contient toutes les images et autres fichiers multimédias utilisés dans vos articles. Vous devrez peut-être utiliser un client FTP ou demander à votre hébergeur de télécharger ce dossier.

Une fois les fichiers en votre possession, créez un fichier ZIP avec la structure suivante :

```
wordpress-export.zip
    ├── export.xml
    └── uploads
        └── 2024
            ├── 01
            │   ├── image1.jpg
            │   └── image2.jpg
            └── 02
                └── image3.jpg
```

Envoyez-nous le fichier ZIP et nous nous occuperons du reste. N'hésitez pas à nous contacter via le chat en direct si vous avez des questions.
