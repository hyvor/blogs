<h1 id="navigation">Liens de navigation</h1>

Les liens de navigation s'affichent dans l'en-tête et le pied de page de votre blog. Vous pouvez les configurer dans la section **Paramètres &rarr; Liens de navigation** de la Console.

<h2 id="create">Créer un lien de navigation</h2>

Pour créer un lien de navigation,

1. Allez dans **Paramètres &rarr; Liens de navigation**
2. Cliquez sur le bouton **Créer une navigation**
3. Remplissez les détails : Nom, URL, Type
4. Cliquez sur le bouton **Ajouter**
