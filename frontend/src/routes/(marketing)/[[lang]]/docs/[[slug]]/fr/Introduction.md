# Introduction

Bonjour cher blogueur 👋,

Gérer un blog n'a jamais été aussi facile. Installer des plugins, suivre les mises à jour et gérer des services ne sont pas faits pour les blogueurs ordinaires. Nous pensons que bloguer devrait être facile pour tout le monde. C'est pourquoi nous avons créé [Hyvor Blogs](/). Tous les aspects techniques sont pris en charge par nous. Vous n'avez qu'à vous concentrer sur l'écriture.

<h2 id="get-started">Comment commencer ?</h2>

Visitez la [Console Hyvor Blogs](https://blogs.hyvor.com/console) pour créer un nouveau blog. La Console est l'endroit où vous gérerez tous vos blogs. Vous pouvez accéder à la Console en utilisant votre compte HYVOR. Chaque compte peut avoir plusieurs blogs.

<h2 id="features">Fonctionnalités</h2>

Hyvor Blogs est une plateforme de blogging tout-en-un. Voici quelques-unes de ses principales fonctionnalités avec des liens pour en savoir plus à leur sujet.

- **[Outils d'écriture puissants](/docs/writing)** - Vous pouvez rédiger vos articles dans l'éditeur de texte enrichi intégré. Ajouter des images, du contenu multimédia riche et des extraits de code est un jeu d'enfant.
- **[Support multilingue](/docs/languages)** - Vous voulez toucher un public plus large ? Activez plusieurs langues pour votre blog et commencez à traduire. Nous prenons également en charge les traductions par IA via DeepL.
- **[Thèmes personnalisables](/docs/theme)** - Vous pouvez choisir un thème dans notre bibliothèque de thèmes ou créer votre propre thème à partir de zéro.
- **[Invitez les membres de votre équipe](/docs/users)** - Rédigez des articles avec les membres de votre équipe. Plusieurs rôles sont disponibles.
- **[Domaine personnalisé](/docs/custom-domain)** - Hébergez votre blog sur votre propre domaine comme example.com ou blog.example.com.
- **[Hébergement en sous-répertoire](/docs/subdirectory)** - Hébergez votre blog dans un sous-répertoire comme example.com/blog. Plusieurs intégrations sont disponibles.
- **[SEO intégré](/docs/seo)** - Hyvor Blogs est conçu en pensant au SEO. La plupart des aspects techniques du SEO sont pris en charge par nous. Vous n'avez qu'à vous concentrer sur l'écriture.
- **[Intégrations via code personnalisé](/docs/custom-code)** - Vous voulez ajouter des analyses, des publicités ou d'autres intégrations ? Ajoutez simplement l'extrait de code dans la section Code personnalisé.

<h2 id="future">Et ensuite ?</h2>

Nous travaillons sur de nombreuses nouvelles fonctionnalités pour rendre le blogging plus facile. En voici quelques-unes. Si vous avez des suggestions, n'hésitez pas à nous contacter.
