# Introduction

Bienvenue sur Hyvor Blogs 👋.

Nous avons créé Hyvor Blogs pour rendre le blogging facile pour tout le monde. Hyvor Blogs regroupe tout ce dont vous avez besoin pour lancer et gérer un blog au sein d'une seule plateforme. Nous nous efforçons de rendre notre plateforme aussi intuitive et conviviale que possible, afin que vous puissiez vous concentrer sur la création de contenu.

<h2 id="get-started">Comment commencer ?</h2>

Visitez la [Console Hyvor Blogs](https://blogs.hyvor.com/console) pour créer un nouveau blog. Il vous sera demandé de créer un compte HYVOR, puis une organisation. Vous pouvez avoir plusieurs blogs au sein de votre organisation. Tous peuvent être accédés et gérés facilement depuis la Console.

<Callout type="info" title="Auto-hébergement">
    Hyvor Blogs est open-source et peut être auto-hébergé gratuitement si vous êtes à l'aise avec les serveurs. Dans ce cas, <a href="/hosting">commencez ici</a>.
</Callout>

<h2 id="features">Fonctionnalités</h2>

Hyvor Blogs offre un large éventail de fonctionnalités :

- **[Éditeur de texte enrichi puissant](/docs/writing)** - Vous pouvez rédiger vos articles dans l'éditeur de texte enrichi intégré. Ajoutez facilement des images, de l'audio, du contenu multimédia riche, des extraits de code, et plus encore.
- **[Support multilingue](/docs/languages)** - Tout est conçu pour prendre en charge plusieurs langues, vous permettant de toucher un public plus large.
- **[Thèmes personnalisables](/docs/themes)** - Vous pouvez choisir un thème dans notre bibliothèque de thèmes ou créer votre propre thème à partir de zéro.
- **[Agent IA](/docs/agent)** - Un assistant intelligent qui peut lire vos articles et vous proposer des suggestions pour les améliorer. Bien entendu, vous pouvez le désactiver à tout moment.
- **[Invitez les membres de votre équipe](/docs/users)** - Donnez à vos coéquipiers accès à votre blog. Plusieurs rôles avec collaboration en temps réel.
- **[Mode Suggestion](/docs/suggestion-mode)** - Suggérez des modifications aux articles de vos coéquipiers, discutez des changements directement dans l'éditeur et collaborez efficacement.
- **[Domaine personnalisé](/docs/custom-domain)** - Hébergez votre blog sur votre propre domaine comme example.com ou blog.example.com.
- **[Hébergement en sous-répertoire](/docs/subdirectory)** - Hébergez votre blog dans un sous-répertoire comme example.com/blog. Plusieurs intégrations sont disponibles.
- **[Sans interface (Headless)](/docs/headless)** - Vous pouvez utiliser Hyvor Blogs en mode sans interface, ce qui vous permet de l'intégrer avec n'importe quel framework frontend ou générateur de site statique.
- **[SEO intégré](/docs/seo)** - Hyvor Blogs est conçu en pensant au SEO. La plupart des aspects techniques du SEO sont pris en charge par nous.
- **[Hyvor Talk pour les commentaires](/docs/hyvor-talk)** - Notre plateforme de commentaires, Hyvor Talk, peut être facilement intégrée à votre blog. Livrée avec une licence gratuite.
- **[Hyvor Post pour les newsletters](/docs/hyvor-post)** - Notre plateforme de newsletters, Hyvor Post, vous permet d'envoyer des newsletters à vos abonnés. Livrée avec une licence gratuite.
- **[Intégrations via code personnalisé](/docs/custom-code)** - Ajoutez d'autres intégrations, telles que des analyses, des formulaires ou des scripts personnalisés à votre blog.
- **[API Console](/docs/api-console)** - Gérez votre blog de manière programmatique, y compris les articles, les utilisateurs et les paramètres, à l'aide de notre API.
- **[Webhooks](/docs/webhooks)** - Configurez des webhooks pour recevoir des notifications en temps réel sur les événements se produisant sur votre blog, comme les nouveaux articles, etc.
