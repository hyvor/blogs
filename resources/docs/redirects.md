## What is redirects ?

Every web page in the internet has an addresses, URL and it stands for `Uniform Resource Locator`. 

Sometimes, content moves from one URL to another URL. That’s when you need a redirect. A redirect automatically makes a browser go from one URL to another URL. And this is also called as URL redirection. 

A redirect can point to any other URL: it doesn’t need to point to the same website. Redirecting to another domain are sometimes referred as cross-domain redirects.

## What are the redirect types ?

There are several type of redirect but in **Hyvor** we supports to types of redirects the are `301, 302`.

### 301
301 redirects known as permanent redirect are used when a page has moved or when a page has been deleted and similar content can be found elsewhere.

Search engines follow the redirect and will add the new URL to the index. Links pointing to the old URL will be counted towards the ranking of the new URL.

### 302
302 redirect known as temporary redirect are used for when a page needs to be temporarily moved, or when the original URL should always be requested.

An “improved” temporary redirect, that will always be treated as temporary by search engines.

## How dose redirects work ?

Redirects are by far the most common method of redirection where the request is handled at the server level. The original request does not load, and the server reads the instructions and delivers a different web page rather than loading the first request.

## When to create a redirect ? 
You should create redirects when:

* You’re moving from one system to another and change URLs because of that.
* You deleted a page and there is similar content available elsewhere.
* You’re merging the content of several pages into one.

## Is redirecting bad?

Redirects are not bad for SEO, but — as with so many things — only if you put them in place correctly. 

A bad implementation might cause all kinds of trouble, from loss of PageRank to loss of traffic. Redirecting pages is a must if you make any changes to your URLs


## How to create, update & delete the redirects.

### Create Redirect

In **Hyvor Blogs** to create an new redirect you will have to click on the create button next to the redirect title. 

And then a popup form will be opened then you will have to include the **Match path and the redirect to path and then select the redirect type as mentioned** and then click on the create button.

### Update Redirect

To update an existing redirect you will have to click on the pencil icon in the right hand side of a specific redirect. 

And then an pop-up form will be displayed with the existing data. And then you will be able to edit that data and click the update button. 

### Delete Redirect

To Delete an existing redirect you will have to click on the trash icon in a specific row then an delete confirmation will be pop-up. And the you will have to confirm the delete.
