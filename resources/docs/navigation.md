# Navigation

You will learn :

* How create header and footer navigation menu.
* How to create, update & delete the navigation menu.
* How to arrange the navigation menu.

Navigation settings: **Console &rarr; Settings &rarr; Navigation**.

## How create header and footer navigation menu

To create an **Header** navigation you will have to click the create Icon next to the `Header Navigation` title.

To create an **Footer** navigation you will have to click the create icon next to the `Footer Navigation` title.

## How to create, update & delete the navigation menu

The navigation create method was been explained in the previous section.

To **Update** an existing navigation you will have to click the pencil icon which is there in front of an specific navigation row. And the again an popup form will be open then you can edit the data as your wish.

To **Delete** an existing navigation you will have to click the trash icon in the end of a selected navigation. Then an delete confirmation form will be popup then you will have to `confirm the delete`. 

## How to arrange the navigation menu

To arrange the navigation menu in the header section or the footer section you can click on the `Hamburger icon` in the left and drag the navigation and drop it in a specific place. 

> But it always should be inside the header navigation section or the footer navigation. We don't support to drag and drop an multiple navigation areas.
