## What is a tag in Hyvor Blogs ?

As you know Hyvor Blogs is not wordpress. In Hyvor Blogs tags are similar to the catagories in wordpress. 

In short, tags are the most general method of grouping content on a Hyvor Blogs. A tag symbolizes a topic or a group of topics that are connected to one another in some way.

Sometimes, a post can belong to many tags at the same time. 

However, it’s perhaps not the best idea to assign more than 2-3 tags to one post. The point here is to have your content neatly organized in a way that makes accessing it easier for the reader.

For instance, if I write a post about knowledge, I’ll put it in the "Knowledge" tag. If I write a article about sports, I’ll put it in “Sports.” But, if I stumble upon some knowledge that involves “Sports, I could add my post to both tags: Knowledge and “Sports.”

## How dose tags work for a single post ?

if you need to create or select an specific tag to a post you can click on the settings button in a specific post then a pop-up will be displayed. 

In that pop-ups basic section you will be able to find the tags. 

Then in that you can type for a new tag and the the tag will be created and the url slug will be created according to the tag name. 

And if you need to select an already created tag you can type the name of the tag and the it will be displayed in a drop down. So then you will be able to select an specific tag.

## How to create, update & delete tags

And also you can find the tags in  **Console &rarr; Settings &rarr; Tags**.

In this you can create update or delete an existing tag.

### Create a new tag

In **Hyvor Blogs** to create an new tag you will have to click on the create button next to the tag title. 

And then a popup form will be opened then you will have to include the **Tag name and if you prefer you can include the slug & description** and then click on the create button.

> If you didn't include the slug it will be created manually according to the name.

### Update Tag

To update an existing tag you will have to click on the pencil icon in the right hand side of a specific tag. 

And then an pop-up form will be displayed with the existing data. And then you will be able to edit that data and then click the update button. 

### Delete Tag

To Delete an existing tag you will have to click on the trash icon in a specific row. And then delete confirmation pop-up will be displayed. And the you will have to confirm the delete.
