# Comments

Comments allow your readers to engage with you. They can increase authority of your blog, and also invite others to participate in conversations and share their opinions.

Because comments are dynamic, Hyvor Blogs does not come with an in-built commenting system. However, HB integrates well with its sister product, [Hyvor Talk](https://talk.hyvor.com), which is a commenting system for any website. It also comes with a reactions widget. We invite you to visit HT website, and see its unique features to make your decision.

> Please note that HB and HT operates independently. Therefore, if you choose to use HT, you will need a separate subscription for that.

Comments Settings: **Console &rarr; Settings &rarr; Comments & Newsletter**.

## Using Hyvor Talk {#hyvor-talk}

First, you have to sign up at [Hyvor Talk](https://talk.hyvor.com/console), and get a website ID. Then, in the Hyvor Blogs comments settings, choose "Hyvor Talk" as the commenting system and paste your website ID. Then, you should then see the Hyvor Talk comments section on your blog posts.

### Moderating

When you set up Hyvor Talk, you usually have to visit the Hyvor Talk Console to moderate comments. This can be a hassle. Let's set up comments moderating inside the Hyvor Blogs Console. First, generate an API key from the [Hyvor Talk Console](https://talk.hyvor.com/console). Then, paste it in "Hyvor Talk API Key" field. That's all you have to do. Now, you can visit the Comments section in the HB Console to view and moderate all comments of your blog.


## Using Other Commenting Systems {#other}

If you choose to use an other commenting system, choose "Other" in comments section and paste the code given by the commenting system in the "Comments Embed Code" field.
