# Users

## Roles {#roles}

There are 6 roles for users. Each user has access to features based on their role.

| Feature | Owner | Admin | Editor | Writer | Contributor | Finance |
| --- | --- | -- | --- | --- | --- | --- |
| Write posts | ✔ | ✔ | ✔ | ✔ | ✔ | |
| Publish posts | ✔ | ✔ | ✔ | ✔ |  | |
| Publish/edit others' posts | ✔ | ✔ | ✔ |  | | |
| Moderate comments | ✔ | ✔ | ✔ | | | |
| Upload media | ✔ | ✔ | ✔ | ✔ | ✔ | |
| Create/edit tags | ✔ | ✔ | ✔ |  | | |
| Add/remove users | ✔ | ✔ | | | | |
| Access to billing | ✔ | ✔ | | | | ✔|
| Edit Theme | ✔ | ✔ | | | | |
| Change blog settings | ✔ | ✔ | | | | |
| Delete Blog | ✔ |  | | | | |
