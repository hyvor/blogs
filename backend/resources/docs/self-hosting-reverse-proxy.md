# Self-hosting using Reverse Proxy

It is possible to set up a server (Apache, NGINX, Caddy, etc.) as a reverse proxy to self-host a blog on a subdirectory. However, we have not yet tested this method nor support it. For now, see [self-hosting using a web framework](self-hosting-web-framework). If that does not work for you and if you need to set up reverse proxy instead, please contact us.
